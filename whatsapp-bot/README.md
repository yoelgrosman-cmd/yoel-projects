# העוזר בוואטסאפ

כותבים לעוזר בוואטסאפ כמו לכל איש קשר. הוא מבין טקסט, תמונות ו-PDF (למשל צילום של פתק מהגן), מנהל רשימת קניות משותפת, שולח תזכורות בעצמו, נותן קישור "הוסף ליומן" בלחיצה, מחפש באינטרנט ושולח סיכום שבועי.
ההוראות וה-skills מגיעים מהתיקייה `assistant/`, כך שכל שינוי שם עולה גם לבוט.

רק המספרים שמופיעים ב-`ALLOWED_NUMBERS` יכולים לדבר איתו. כל מי שאינו ברשימה לא יקבל תשובה. רשימת הקניות, הפרופיל והתזכורות משותפים לכל בני הבית.

## מה צריך (פעם אחת, כ-30–45 דקות)

### 1. מפתח ל-Claude
1. נכנסים ל-https://console.anthropic.com, נרשמים ומוסיפים אמצעי תשלום.
2. בתפריט **API Keys** לוחצים **Create Key** ושומרים את המפתח (`sk-ant-...`).

### 2. חשבון Cloudflare (השרת)
1. נרשמים ב-https://dash.cloudflare.com.
2. מומלץ לשדרג ל-**Workers Paid** (‏5$ לחודש). בתוכנית החינמית ייתכן שהבוט ייתקע בגלל מגבלות זמן.
3. ב-**My Profile ← API Tokens ← Create Token** בוחרים בתבנית **Edit Cloudflare Workers** ושומרים את הטוקן.
4. מעתיקים את ה-**Account ID** מעמוד הבית של החשבון.

### 3. וואטסאפ (Meta)
1. נכנסים ל-https://developers.facebook.com, יוצרים אפליקציה מסוג **Business** ומוסיפים לה את המוצר **WhatsApp**.
2. ב-**WhatsApp ← API Setup** מקבלים מספר בדיקה. אפשר גם לחבר מספר משלכם, אבל הוא צריך להיות מספר שעוד לא רשום באפליקציית וואטסאפ.
   - מעתיקים את ה-**Phone number ID**.
   - במספר הבדיקה מוסיפים את המספרים שלכם תחת **To**, כי מספר בדיקה עונה רק למספרים מאושרים.
3. **טוקן קבוע**: ב-https://business.facebook.com ← **Settings ← System users** יוצרים System User, נותנים לו גישה לאפליקציה ומפיקים טוקן עם ההרשאות `whatsapp_business_messaging` ו-`whatsapp_business_management`. הטוקן הזמני שמופיע במסך ה-API Setup פג אחרי 24 שעות.
4. ב-**App settings ← Basic** מעתיקים את ה-**App secret**.
5. ממציאים מילת אימות כלשהי, למשל `my-assistant-2026`. זה יהיה ה-**Verify token**.

### 4. שמירת הסודות ב-GitHub
ב-repo נכנסים ל-**Settings ← Secrets and variables ← Actions ← New repository secret** ומוסיפים:

| שם | ערך |
|---|---|
| `ANTHROPIC_API_KEY` | המפתח משלב 1 |
| `CLOUDFLARE_API_TOKEN` | הטוקן משלב 2 |
| `CLOUDFLARE_ACCOUNT_ID` | ה-Account ID משלב 2 |
| `WHATSAPP_TOKEN` | הטוקן הקבוע משלב 3 |
| `WHATSAPP_PHONE_NUMBER_ID` | ה-Phone number ID |
| `WHATSAPP_APP_SECRET` | ה-App secret |
| `WHATSAPP_VERIFY_TOKEN` | מילת האימות שהמצאתם |
| `ALLOWED_NUMBERS` | המספרים של בני הבית, בפורמט בינלאומי ומופרדים בפסיקים: `972501234567,972521234567` |

### 5. העלאה לאוויר
ב-**Actions ← Deploy WhatsApp assistant ← Run workflow**. בסוף הריצה תופיע כתובת בסגנון:
`https://assistant-whatsapp-bot.<שם>.workers.dev`

### 6. חיבור וואטסאפ לשרת
ב-Meta נכנסים ל-**WhatsApp ← Configuration ← Webhook ← Edit**:
- **Callback URL**: הכתובת משלב 5 עם `/webhook` בסוף.
- **Verify token**: מילת האימות.

לוחצים **Verify and save**, ואחר כך תחת **Webhook fields** מסמנים **messages**.

### 7. תבנית להודעות יזומות
וואטסאפ מאפשר לבוט לכתוב בחופשיות רק בתוך 24 שעות מההודעה האחרונה שלכם. כדי שתזכורות והסיכום השבועי יגיעו גם אחרי זה, צריך תבנית מאושרת:
**WhatsApp Manager ← Message templates ← Create**
- קטגוריה: **Utility**
- שם: `assistant_update`
- שפה: **Hebrew**
- גוף ההודעה: `עדכון מהעוזר שלך: {{1}}`

האישור לוקח בדרך כלל כמה דקות עד כמה שעות.

### 8. מתחילים
שולחים "היי" למספר של הבוט, והוא יתחיל בשאלות ההיכרות.

## עלויות (הערכה)
- **Claude**: לפי שימוש. הודעה רגילה עולה בערך 2–10 סנט, וחיפוש באינטרנט יקר יותר. בשימוש משפחתי רגיל זה בערך 5–20$ לחודש.
- **Cloudflare**: 5$ לחודש (מומלץ).
- **וואטסאפ**: שיחות שאתם פותחים חינמיות. הודעות יזומות דרך התבנית עולות כמה אגורות כל אחת.

## מגבלות
- **אין חיבור ישיר ליומן**: הבוט לא כותב ישירות ל-Google Calendar. הוא שולח קישור "הוסף ליומן" שנלחץ פעם אחת, ובנוסף שולח בעצמו תזכורות בוואטסאפ.
- **אין תשלומים ואין שליחת הודעות לאחרים**: הבוט לא מתחבר לחשבונות, לא משלם ולא שולח הודעות לאנשים אחרים. הוא מכין הכל (קישור, עגלה, נוסח הודעה), ואת הלחיצה האחרונה עושים אתם.
- **אין הודעות קוליות**: הבוט עוד לא מבין הודעות קוליות.
