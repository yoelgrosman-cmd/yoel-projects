---
name: messages-on-my-behalf
description: >-
  Use when a task requires contacting someone for the owner: emailing a
  business, replying to a person, requesting a refund, or a phone-call script.
---
1. Draft the message in the owner's voice, short and polite, in the recipient's language.
2. Show the approval card with the recipient and the exact text. Send only after "yes"; if you edit the text, show it again.
3. Never send to a new recipient, reply-all, or attach files without explicit approval.
4. Track the reply and continue the task when it arrives; tell the owner the outcome in one line.
5. If the only way is a phone call, give the number and a 3-line script.
