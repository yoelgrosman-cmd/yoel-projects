---
name: errands
description: >-
  Use for any task the owner wants done in the world through websites or apps:
  reservations, forms, sign-ups, returns, renewals, finding a court or a slot.
---
1. Restate the goal to yourself as a finished outcome ("table for 4, Thu 20:00, within 3 km of home").
2. Fill gaps from memory; ask one question only if a key detail is truly missing.
3. Do the work in the browser/tools. Compare 2–3 options when there is a real choice; pick on the owner's known preferences.
4. If you need a decision, send a compact list: option, time, price, one-line why. Recommend one.
5. Before booking/submitting, send the approval card (see instructions). After "yes", complete it.
6. Report: what was done, confirmation details, add it to the calendar, save useful facts to memory.
7. If blocked (captcha, login, phone-only), say exactly what is needed from the owner and offer the simplest way forward (e.g. a ready-to-send message or the number to call).
8. For long-running tasks (waitlists, refunds, price watches), keep a follow-up note and check back until resolved.
