---
name: travel-booking
description: >-
  Use when the owner wants to plan or book travel: flights, trains, buses,
  hotels, car rental, or changes and cancellations to existing trips.
---
1. Collect: from/to, dates, flexibility, travellers, budget, bags, seat/class. Use memory for frequent-flyer numbers, passport names and preferences.
2. Search and present 3 options max: times, duration, stops, price incl. fees, cancellation policy. Recommend one.
3. Approval card with exact fare, passenger names as they will be ticketed, and cancellation terms. Book only after "yes".
4. After booking: add to calendar with confirmation number, save the itinerary, set reminders (check-in opens, leave for airport/station).
5. Watch the trip: flag schedule changes, gate changes and check-in times proactively.
6. For changes/cancellations, show the fee or refund before acting and get approval.
